# 🎵 Suno AI Song Composer

![Suno AI Song Composer Banner](https://images.unsplash.com/photo-1619983081593-e22f5899fa24?q=80&w=1280&auto.format&fit=crop)

### เปลี่ยนไอเดียและความรู้สึกของคุณให้กลายเป็นเพลงที่สมบูรณ์แบบสำหรับ Suno AI

[![Deploy with Vercel](https://vercel.com/button)](https://suno-ai-by-fung-yub11.vercel.app/)

แอปพลิเคชันผู้ช่วยสร้างสรรค์ที่ออกแบบมาเพื่อเปลี่ยนความคิดของคุณให้เป็นข้อมูลเพลงที่พร้อมใช้งานกับ Suno AI ได้ทันที ขับเคลื่อนด้วยพลังของ Google Gemini API เพื่อให้คุณสร้างสรรค์ผลงานได้อย่างไร้ขีดจำกัด

---

## 🚀 เริ่มต้นใช้งาน

**ข้อกำหนดเบื้องต้น:** คุณต้องมี **Google Gemini API Key** ของคุณเองเพื่อใช้งานแอปพลิเคชันนี้

1.  **รับ API Key ของคุณ:**
    - ไปที่ [Google AI Studio](https://aistudio.google.com/app/apikey)
    - คลิก "**Create API key in new project**" เพื่อสร้างคีย์ใหม่
    - คัดลอก API Key ที่สร้างขึ้น
2.  **ป้อน API Key ของคุณ:**
    - เมื่อคุณเปิดแอปพลิเคชันเป็นครั้งแรก หน้าต่างจะปรากฏขึ้นเพื่อขอ API Key ของคุณ
    - วางคีย์ของคุณลงในช่องที่กำหนด แล้วกดบันทึก
    - คีย์ของคุณจะถูกเก็บไว้อย่างปลอดภัยในเบราว์เซอร์ของคุณเท่านั้น
3.  **เริ่มต้นสร้างสรรค์!**

---

## ✨ ฟีเจอร์หลัก

- **🔑 การจัดการ API Key:** ผู้ใช้สามารถใส่และจัดการ Gemini API Key ส่วนตัวได้อย่างปลอดภัย
- **💡 คู่มือไอเดียสร้างสรรค์:** แหล่งรวมธีมเพลงยอดนิยมเพื่อจุดประกายความคิดของคุณ
- **📝 พิมพ์เขียวเรื่องเล่า (Narrative Blueprint):** สร้างเพลงที่มีมิติด้วยแก่นเรื่อง, เรื่องราว, อารมณ์, และภาพสัญลักษณ์
- **💾 บันทึกและโหลดพรีเซ็ต:** บันทึกการตั้งค่าสไตล์และโครงสร้างที่คุณชื่นชอบไว้ใช้ซ้ำได้อย่างรวดเร็ว
- **🎤 ตัวอย่างเสียงร้อง AI:** ฟังตัวอย่างเสียงร้องของเนื้อเพลงที่คุณสร้างขึ้นได้ทันที
- **✍️ สตูดิโอปรับแก้ด้วย AI (AI-Powered Revisions):** ส่งเพลงที่สร้างแล้วกลับไปให้ AI แก้ไขตามคำสั่งของคุณ
- **🌐 รองรับหลายภาษา:** สร้างสรรค์ผลงานได้ทั้งภาษาไทย, อังกฤษ, จีน, ญี่ปุ่น และเกาหลี
- **🎨 ปรับแต่งได้หลากหลาย:** เลือกแนวเพลง, อารมณ์, จังหวะ, และเครื่องดนตรีได้อย่างอิสระ
- **🔧 โหมดขั้นสูง:** กำหนดโครงสร้างเพลงเอง, ใส่เพลง/ศิลปินที่เป็นแรงบันดาลใจ, และปรับค่าเฉพาะของ Suno AI ได้

---

## 🛠️ เทคโนโลยีที่ใช้

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **AI Model:** Google Gemini API (`gemini-3.1-pro-preview`, `gemini-2.5-flash`, `gemini-3.6-flash`)
